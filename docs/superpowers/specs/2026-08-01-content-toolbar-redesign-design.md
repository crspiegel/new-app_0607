# 페이지2 툴바 리디자인 — 아이콘 통일·GAME/SONG 태그·고정 크기 버튼 (2026-08-01)

## 목적

관리자가 레벨 1~3의 Game/Song 버튼을 도서명으로 바꿀 예정인데, 툴바 버튼이
텍스트 길이에 맞춰 늘어나는 구조라 긴 도서명이 레이아웃을 깨뜨린다. 아이콘도
유형별로 제각각(♪★🧩🎯♫🎶)이었다.

## 사용자와 확정한 결정

1. **아이콘 통일 (전 레벨, 원형 배경 제거):** opening/ending → 영상(재생 삼각형),
   game/game2 → 게임(게임패드), unit/song1/song2 → 음악(음표). 라인 SVG
   (`ICON_SVGS`, currentColor 스트로크), 26px 원형 배경 삭제.
2. **GAME/SONG 모서리 태그 — 레벨 1~3(6버튼 툴바)만:** 슬롯 기반 자동
   (game/game2 → GAME 오렌지 `--tag-game:#ff9600`, song1/song2 → SONG
   `--tag-song:var(--macaw-blue)`). 버튼 오른쪽 위 모서리 겹침 필.
   **Beginner는 태그 제외, 기본 이름 유지** ("Game", "Unit Song").
3. **기본 이름 다듬기 (레벨 2~4):** "I Sit Game"→"I Sit" 등 접미사 제거 —
   태그가 유형을 표시. 관리자 저장 커스텀 이름은 불변.
4. **고정 크기 버튼 (--wide 툴바만):** 균등폭(flex/grid 1fr), 최대 2줄
   줄바꿈 → `fitToolbarText()` 폰트 축소(하한 11px) → 말줄임 3단 안전망.
   Beginner 4버튼 레이아웃은 기존 그대로.
5. **플레이어 제목:** song 태그 슬롯 = "도서명 · Song" 합성 (데이터 기반 —
   기존 `span:last-child` DOM 스크래핑은 태그와 충돌하므로 제거).

## 구조 요점

- `TOOLBAR_BUTTONS` 항목에 `icon` 키(`video|game|music`)와 `tag`(`game|song`,
  태그 슬롯만) 필드. 렌더러/제목 합성/테스트 모두 이 데이터 기반.
- 아이콘은 `span.content-type-icon` 래퍼 유지(브레이크포인트 크기 규칙 재사용),
  내부에 SVG (`.content-type-icon svg` 규칙이 스트로크 지정).
- 768~899px 태블릿의 아이콘 숨김 규칙 삭제 — 원형이 사라져 공간 여유 생김.
- ⚠ **--wide 기본 규칙의 좌우 50px 패딩이 모바일 규칙보다 특이도가 높아**
  모바일 1fr 셀을 잠식 → 모바일 --wide 블록에서 6px로 재정의 (실측으로 발견).
- fitText는 렌더 직후 rAF + 디바운스 리사이즈 + `document.fonts.ready`에서 실행.

## 수용 기준 (qa 51/51 green + 스크린샷 매트릭스, 2026-08-01)

- 전 레벨 아이콘이 유형별(영상/게임/음악) 라인 SVG로 통일, 원형 배경 없음.
- 레벨 1~3에서 GAME×2·SONG×2 태그 표시(클리핑 없음), Beginner 태그 0개.
- 긴 도서명에도 버튼 폭/높이 불변(±1.5px), 폰트 축소·2줄·말줄임 동작.
- 플레이어 제목: 태그 슬롯 "도서명 · Song", 무태그 슬롯 라벨 그대로.
- Beginner 레이아웃(데스크톱 내용 크기·포트레이트 세로 스택) 기존과 동일.
